# 信息检索与数据挖掘 题库 2025

# 单选题

1. **生成式人工智能（Generative AI）的核心目标是（ ）**

    A\. 从有限选项中选择最优结果（如分类、检测）

    B\. 基于规则执行固定任务（如数据计算、文件转换）

    C\. 从海量数据中提取关键信息（如摘要、检索）

    D\. 从近乎无穷的可能中生成复杂且有结构的物件（如文字、图像、视频）

- 答案：**D\. 从近乎无穷的可能中生成复杂且有结构的物件（如文字、图像、视频）**

- 得分点：**明确生成式 AI 的核心定位（生成 \+ 复杂结构）**

- 选项解析：
    - A\. 从有限选项中选择最优结果（如分类、检测）：**是判别式 AI 的目标**，非生成式，排除；

    - B\. 基于规则执行固定任务（如数据计算、文件转换）：**是传统程序或工具的特性**，排除；

    - C\. 从海量数据中提取关键信息（如摘要、检索）：**是信息抽取类任务，非生成式核心**，排除。

2. **大型语言模型（LLM）的核心运作机制本质是（ ）**

    A\. 基于规则库的关键词匹配与应答

    B\. 直接调用互联网实时数据生成答案

    C\. 基于 autoregressive 生成策略的 “文字接龙”，逐 token 预测下一个最优结果

    D\. 模拟人类思维过程的推理与决策

- 答案：**C\. 基于 autoregressive 生成策略的 “文字接龙”，逐 token 预测下一个最优结果**

- 得分点：**掌握 LLM 的核心生成逻辑**

- 选项解析：
    - A\. 基于规则库的关键词匹配与应答：**是早期聊天机器人的逻辑**，排除；

    - B\. 直接调用互联网实时数据生成答案：LLM 核心**依赖预训练数据**，实时数据需工具辅助，排除；

    - D\. 模拟人类思维过程的推理与决策：**是高阶能力，核心运作机制仍是逐 token 生成**，排除。

3. **Transformer 架构中，Self\-Attention 机制的核心作用是（ ）**

    A\. 加速模型训练速度，降低计算复杂度

    B\. 捕捉输入序列中 token 之间的关联关系，实现全局信息交互

    C\. 对输入 token 进行分类标注，明确语义角色

    D\. 压缩输入序列长度，保留核心信息

- 答案：**B\. 捕捉输入序列中 token 之间的关联关系，实现全局信息交互**

- 得分点：**理解 Self\-Attention 的核心功能**

- 选项解析：
    - A\. 加速模型训练速度，降低计算复杂度：**Self\-Attention 计算复杂度较高**，排除；

    - C\. 对输入 token 进行分类标注，明确语义角色：**是命名实体识别等任务的目标**，排除；

    - D\. 压缩输入序列长度，保留核心信息：**是池化（Pooling）层的作用**，排除。

4. **生成式 AI 模型训练流程中，“预训练（Pre\-train）” 阶段的核心数据特点是（ ）**

    A\. 海量无标注数据（如网络文本、图像库），实现通用能力学习

    B\. 少量有标注数据（如指令 \- 应答对），实现任务适配

    C\. 人类反馈数据（如偏好评分、修正意见）

    D\. 特定领域结构化数据（如专业文档、标注样本）

- 答案：**A\. 海量无标注数据（如网络文本、图像库），实现通用能力学习**

- 得分点：**掌握预训练阶段的核心特征**

- 选项解析：
    - B\. 少量有标注数据（如指令 \- 应答对），实现任务适配：**是微调（Fine\-tune）阶段的数据特点**，排除；

    - C\. 人类反馈数据（如偏好评分、修正意见）：**是 RLHF 阶段的数据特点**，排除；

    - D\. 特定领域结构化数据（如专业文档、标注样本）：**是领域适配微调的数据特点**，排除。

5. **LLM 生成过程中 “掷骰子（Sampling）” 策略的核心目的是（ ）**

    A\. 保证生成结果的绝对准确性，降低幻觉概率

    B\. 加速生成速度，减少计算资源消耗

    C\. 引入随机性，避免生成结果重复单调，提升多样性

    D\. 强制模型遵循语法规则，提升输出规范性

- 答案：**C\. 引入随机性，避免生成结果重复单调，提升多样性**

- 得分点：**理解 Sampling 策略的设计逻辑**

- 选项解析：
    - A\. 保证生成结果的绝对准确性，降低幻觉概率：**Sampling 会增加随机性，可能提升幻觉概率**，排除；

    - B\. 加速生成速度，减少计算资源消耗：**与生成速度无关**，排除；

    - D\. 强制模型遵循语法规则，提升输出规范性：语法规范性**依赖预训练数据和模型架构**，排除。

    A\. 是模型训练的初始阶段，用于学习通用能力

    B\. 核心是通过人类偏好反馈优化模型输出，实现 Alignment（对齐）

    C\. 仅需少量无标注数据即可完成训练

    D\. 主要目的是扩大模型参数量，提升拟合能力

- 答案：**B\. 核心是通过人类偏好反馈优化模型输出，实现 Alignment（对齐）**

- 得分点：**掌握 RLHF 的核心作用**

- 选项解析：
    - A\. 是模型训练的初始阶段，用于学习通用能力：预训练阶段学习通用能力，**RLHF 是后续优化阶段**，排除；

    - C\. 仅需少量无标注数据即可完成训练：**RLHF 依赖大量人类标注的反馈数据**，排除；

    - D\. 主要目的是扩大模型参数量，提升拟合能力：**与参数量无关，核心是优化输出质量**，排除。

**1\. 在信息检索的向量空间模型中，余弦相似度计算通常基于TF\-IDF权重。以下关于TF\-IDF的说法，哪一项最准确？**

8. 评价指标 F\-measure（F值） 是哪两个指标的调和平均？

11. 假设某次检索返回了 10 个文档，其中 4 个是相关的。已知整个文档集中总共有 8 个相关文档。请问本次检索的 **Recall \(召回率\)** 是多少？

A\. 0\.5 \(50%\)

B\. 0\.8 \(80%\)

C\. 0\.2 \(20%\)

D\. 0\.4 \(40%\)

答案：A

解析：Recall = \(检索到的相关文档数\) / \(文档集中所有相关文档的总数\) = 4 / 8 = 0\.5。而D为Precision \(准确率/精度\)，即检索到的相关文档占检索到的总文档的比例 \(4/10\)。

12. 在评估指标中，**F\-measure** \(或 F1 score\) 是 Precision 和 Recall 的什么平均值？

A\. Weighted Average \(加权平均\)

B\. Geometric Mean \(几何平均\)

C\. Harmonic Mean \(调和平均\)

D\. Arithmetic Mean \(算术平均\)

答案：C

解析：调和平均数强调较小值的影响。只有当 Precision 和 Recall 都较高时，F\-measure 才会高；如果其中一项很低，F\-measure 会被拉低。

13. 在用于信息检索的 **Language Models \(语言模型\)** 方法中，我们通常如何对文档进行排序？

B\. 根据文档中句子的语法正确性

15. 在语言模型中，为什么要使用 **Smoothing \(平滑\)** 技术（如 Jelinek\-Mercer 或 Dirichlet 平滑）？

B\. 为了计算更快的余弦相似度

D\. 为了移除停用词

答案：A

解析：如果查询中的某个词在文档中未出现，最大似然估计会给出 0 概率。因为查询是乘积形式（AND关系），这会导致整个文档的得分为 0。平滑通过给未见词分配非零概率来解决此问题。

3. 梯度下降算法中，学习率（η）的作用是？（ ）

A\. 控制每次参数更新的步长 B\. 决定损失函数的类型 C\. 固定参数的初始值 D\. 区分训练集和测试集

答案：A

解析：学习率η是梯度下降的核心超参数，控制每次参数更新的幅度（步长）：η过大会导致参数震荡不收敛，η过小会导致训练速度过慢。

4. 以下关于“过拟合（Overfitting）”的描述，正确的是？（ ）

A\. 模型在训练集上误差大，测试集上误差也大 B\. 模型在训练集上误差小，测试集上误差大 C\. 模型复杂度越低，越容易过拟合 D\. 过拟合是由于训练数据过多导致的

答案：B

解析：过拟合是模型过度贴合训练数据的细节（包括噪声），导致在未见过的测试数据上泛化能力差，表现为训练误差小、测试误差大。

5. 正则化（Regularization）在线性回归中的核心作用是？（ ）

答案：B

解析：正则化通过在损失函数中加入参数惩罚项（如L1、L2正则），限制参数的绝对值大小，使模型函数更平滑，避免过度拟合训练数据中的噪声。

6. 线性回归中，模型复杂度与泛化能力的关系是？（ ）

A\. 模型越复杂，泛化能力一定越强 B\. 模型越简单，泛化能力一定越强 C\. 适当复杂度的模型泛化能力最优，过简或过繁都会下降 D\. 模型复杂度与泛化能力无关

答案：C

解析：模型过简单（如仅含一个特征）会欠拟合（训练误差和测试误差都大）；过复杂（如高次多项式特征）会过拟合（训练误差小、测试误差大）；只有适当复杂度的模型能平衡拟合与泛化，表现最优。

7. 以下哪种情况最可能导致线性回归模型过拟合？（ ）

解析：训练数据少而特征维度高时，模型容易“死记硬背”训练数据的细节，无法学习到普遍规律，进而导致过拟合。

1. 逻辑回归的核心用途是？（ ）

解析：Softmax函数将多个线性输出（z₁,z₂,…,zₖ）转换为对应的类别概率（p₁,p₂,…,pₖ），满足Σpᵢ=1，适配多分类的概率解释需求。

1. 神经网络中“全连接前馈网络（Fully Connect Feedforward Network）”的核心特征是？（ ）

9. Attention机制在序列到序列模型中的作用是？（ ）

答案：B

解析：Attention机制允许解码器生成每个输出词时，计算输入序列各位置的权重，聚焦与当前输出相关的输入信息，解决长序列中上下文向量信息丢失的问题。

1. 自注意力（Self\-attention）的核心作用是？（ ）

A\. 仅处理图像数据 B\. 建模向量集合中元素间的依赖关系，自适应关注相关元素 C\. 减少参数数量 D\. 替代梯度下降优化

答案：B

解析：自注意力通过计算向量间的注意力分数，捕捉集合中元素的关联（如文本中词语的语义依赖），无需预设固定窗口，自适应聚焦相关信息。

2. 多头自注意力（Multi\-head Self\-attention）的核心优势是？（ ）

A\. 增加参数数量 B\. 同时捕捉多种类型的依赖关系（如语义、语法依赖） C\. 仅处理短序列 D\. 无需位置编码

答案：B

解析：多个头分别学习不同的注意力模式，捕捉不同类型的关联（如一个头关注语法结构，一个头关注语义关联），融合后提升特征表达能力。

4. 位置编码（Positional Encoding）的核心用途是？（ ）

A\. 增加向量维度 B\. 为序列向量注入位置信息，解决自注意力无时序感知的问题 C\. 减少注意力计算量 D\. 替代多头注意力

答案：B

解析：自注意力本身不区分元素顺序（如文本中词语的位置），位置编码通过添加固定或可学习的位置向量，让模型感知序列的时序关系。

5. 自注意力（Self\-attention）与CNN的关系是？（ ）

A\. CNN是自注意力的简化版（仅关注局部感受野） B\. 自注意力是CNN的简化版 C\. 两者结构完全无关 D\. 自注意力仅处理文本，CNN仅处理图像

答案：A

解析：CNN的局部感受野是固定的，仅能关注局部元素；自注意力可视为“感受野可学习的CNN”，能自适应关注全局或局部元素，灵活捕捉依赖关系。

6. 自注意力（Self\-attention）与RNN的核心区别在于？（ ）

A\. 自注意力支持并行计算，RNN需串行处理序列 B\. 自注意力无记忆能力，RNN有记忆能力 C\. 自注意力仅处理长序列，RNN仅处理短序列 D\. 自注意力无需训练，RNN需训练

答案：A

解析：自注意力可同时计算所有元素的注意力分数，支持并行处理；RNN需按时序逐元素处理，串行计算，效率较低。

7. 以下哪种任务不适合使用自注意力模型？（ ）

A\. 机器翻译（需捕捉词语语义依赖） B\. 图像识别（需捕捉像素局部关联） C\. 静态表格数据的分类（无元素间依赖） D\. 情感分析（需捕捉上下文语义）

答案：C

解析：自注意力的核心优势是建模元素间依赖，静态表格数据的特征间无时序或关联依赖，使用全连接网络即可，无需自注意力。

9. 针对超长序列（如长文本、语音），自注意力的优化方式是？（ ）

A\. 截断自注意力（仅关注局部窗口内元素） B\. 增加多头数量 C\. 取消位置编码 D\. 改用RNN

答案：A

解析：超长序列的自注意力计算量为O\(n²\)（n为序列长度），截断自注意力通过限制关注范围（如仅关注前后k个元素），将计算量降至O\(nk\)，提升效率。

10. 自注意力在图像任务中的应用方式是？（ ）

A\. 将图像视为像素向量集合，直接应用自注意力 B\. 将图像分割为patch（如16×16像素块），视为向量序列 C\. 仅关注图像的局部区域 D\. 无需预处理，直接输入图像

答案：B

解析：图像直接作为像素向量集合时，序列长度过长（如224×224=50176），计算量过大；将图像分割为patch后，序列长度大幅减少（如224/16=14，序列长度14×14=196），适配自注意力计算。

1. Transformer模型的核心创新是？（ ）

A\. 仅使用RNN建模时序依赖 B\. 仅使用CNN提取局部特征 C\. 完全基于自注意力机制，替代RNN和CNN D\. 无需位置编码

答案：C

解析：Transformer摒弃了RNN的串行计算和CNN的固定感受野，完全基于自注意力机制建模依赖关系，支持并行计算，是NLP领域的革命性创新。

2. Transformer的Encoder模块的核心组成部分不包括？（ ）

A\. 多头自注意力（Multi\-Head Attention） B\. 前馈神经网络（FFN） C\. 掩码自注意力（Masked Self\-Attention） D\. 层归一化（Layer Norm）\+ 残差连接

答案：C

解析：掩码自注意力是Decoder的核心组件，用于避免未来信息泄露；Encoder使用普通多头自注意力，无掩码机制。

3. Transformer的Decoder模块中，掩码自注意力（Masked Self\-Attention）的作用是？（ ）

A\. 捕捉输入序列的全局依赖 B\. 避免解码时获取未来位置的信息（如生成第i个词时看不到第i\+1个词） C\. 减少参数数量 D\. 替代前馈神经网络

答案：B

解析：解码采用自回归方式，掩码自注意力通过遮挡未来位置的注意力分数，确保生成当前词时仅依赖已生成的词，避免信息泄露。

4. Transformer中“交叉注意力（Cross Attention）”的作用是？（ ）

A\. 建模Encoder输出与Decoder输出之间的依赖（如机器翻译中目标语言与源语言的关联） B\. 仅建模Encoder内部的依赖 C\. 仅建模Decoder内部的依赖 D\. 替代多头自注意力

答案：A

解析：交叉注意力是Decoder的组件，其Query来自Decoder的隐藏状态，Key和Value来自Encoder的输出，实现Decoder对Encoder输入序列的关注，适配序列到序列任务。

5. Transformer的位置编码（Positional Encoding）的核心目的是？（ ）

A\. 增加输入向量的维度 B\. 为序列注入位置信息，弥补自注意力无时序感知的缺陷 C\. 减少注意力计算量 D\. 替代交叉注意力

答案：B

解析：自注意力仅关注向量间的关联，不区分位置顺序，位置编码通过添加固定或可学习的位置向量，让模型感知序列的时序关系，保证任务正确性（如文本生成的语序）。

6. 以下哪种任务不是Transformer的典型应用？（ ）

A\. 机器翻译（Seq2seq任务） B\. 文本分类（BERT模型） C\. 静态表格数据回归 D\. 语音识别（语音→文本的Seq2seq任务）

答案：C

解析：Transformer擅长建模序列依赖，静态表格数据无时序或关联依赖，无需使用Transformer，全连接网络或简单模型即可满足需求。

7. BERT模型的核心基于Transformer的哪个部分？（ ）

A\. 仅Encoder B\. 仅Decoder C\. Encoder\+Decoder D\. 交叉注意力

答案：A

解析：BERT（Bidirectional Encoder Representations from Transformers）仅使用Transformer的Encoder模块，通过双向自注意力捕捉上下文语义，适配文本分类、问答等理解类任务。

8. Transformer的自回归解码（Autoregressive Decoding）的特点是？（ ）

A\. 一次性生成完整输出序列 B\. 逐词生成输出序列，每一步依赖前一步的结果 C\. 无需位置编码 D\. 仅使用交叉注意力

答案：B

解析：自回归解码按时序逐元素生成输出，如机器翻译中逐词生成目标语言文本，每一步的生成依赖已生成的词和Encoder的输入。

9. Transformer中“层归一化（Layer Norm）”的作用是？（ ）

A\. 加速模型训练，缓解梯度消失 B\. 增加参数数量 C\. 减少序列长度 D\. 替代残差连接

答案：A

解析：层归一化对每层的输入进行标准化，稳定激活值的分布，加速训练收敛，配合残差连接进一步缓解梯度消失问题。

10. Transformer与传统Seq2seq模型（RNN\-based）的核心优势是？（ ）

A\. 支持并行计算，训练效率更高 B\. 仅能处理短序列 C\. 无需位置编码 D\. 参数数量更少

答案：A

解析：传统RNN\-based Seq2seq需串行处理序列，效率低；Transformer的自注意力支持并行计算，可同时处理所有元素，大幅提升训练和推理效率。

1. BERT模型的自监督预训练任务不包括以下哪项？（ ）

3. GPT系列模型的核心预训练任务是？（ ）

4. BERT与GPT的核心结构差异是？（ ）

A\. BERT仅用Transformer的Encoder，GPT仅用Decoder B\. BERT仅用Decoder，GPT仅用Encoder C\. 两者均使用Encoder\+Decoder D\. 结构完全一致，仅预训练数据不同

答案：A

5. BERT的“微调（Fine\-tune）”指的是？（ ）

答案：B

解析：微调是利用预训练模型的通用语义表示，通过少量标注数据微调部分参数（或全参数），使模型适配具体下游任务（如文本分类、问答）。

6. 以下哪种任务更适合使用GPT而非BERT？（ ）

A\. 文本情感分析 B\. 命名实体识别 C\. 诗歌生成 D\. 自然语言推理

解析：GPT是生成式模型，擅长文本生成类任务（如诗歌、对话）；BERT是理解式模型，更适配分类、识别、推理等任务。

7. BERT预训练中的“掩码token预测”策略中，被掩码的token会被替换为？（ ）

8. 零样本学习（Zero\-shot Learning）在BERT中的应用场景是？（ ）

9. T5（Transfer Text\-to\-Text Transformer）模型的核心创新是？（ ）

A\. 仅聚焦语义理解 B\. 仅聚焦文本生成 C\. 将所有NLP任务统一为“文本到文本”的Seq2seq任务 D\. 无需预训练

1. 语言模型（LM）在信息检索中的核心排序依据是？（ ）

10. 以下关于LMIR（语言模型检索）、BM25、VSM的共性说法，错误的是？（ ）

1. 信息检索中“倒排索引（Inverted Index）”的核心组成部分是？（ ）

A\. 文档\-词项矩阵 B\. 词典（Dictionary）\+ postings列表 C\. 仅词项列表 D\. 仅文档ID列表

答案：B

解析：倒排索引由两部分构成——词典（存储词项、文档频率、postings列表指针）和postings列表（存储包含该词项的文档ID，可选位置信息），是现代IR系统的核心数据结构。

2. 词项\-文档关联矩阵（Term\-document incidence matrix）的主要问题是？（ ）

A\. 无法支持布尔查询 B\. 存储稀疏，浪费空间 C\. 查询速度快 D\. 仅支持单词查询

答案：B

解析：该矩阵为稀疏矩阵（多数元素为0），当文档和词项数量庞大时，存储成本极高，无法实际应用，倒排索引通过仅存储非零元素解决此问题。

3. 布尔检索模型的核心特点是？（ ）

A\. 按相关性排序返回文档 B\. 文档要么匹配查询条件，要么不匹配（精确匹配） C\. 仅支持单词查询 D\. 无需索引结构

答案：B

解析：布尔模型基于布尔逻辑（AND/OR/NOT），文档与查询的匹配是二元判断（匹配/不匹配），不涉及相关性排序，是早期IR系统的基础模型。

4. 处理短语查询（如“Stanford University”）的核心数据结构是？（ ）

A\. 普通倒排索引（仅存文档ID） B\. 位置索引（Positional Index） C\. 词项\-文档矩阵 D\. 哈希表

答案：B

解析：位置索引在postings列表中存储词项在文档中的具体位置，可通过验证词项的位置连续性实现短语查询，普通倒排索引无法判断词项在文档中的顺序。

5. 倒排索引构建流程的正确顺序是？（ ）

A\. 分词→归一化→排序→构建词典\+postings列表 B\. 构建词典→分词→排序→postings列表 C\. 排序→分词→归一化→构建索引 D\. 归一化→排序→分词→构建索引

答案：A

解析：倒排索引构建步骤为：文本分词→归一化（大小写、词干提取等）→生成（词项\-文档ID）对→按词项\+文档ID排序→合并重复项，构建词典和postings列表。

7. 查询优化中，布尔AND查询的最优处理顺序是？（ ）

A\. 按词项文档频率降序处理 B\. 按词项文档频率升序处理 C\. 随机顺序 D\. 按词项字母顺序

答案：B

解析：按文档频率升序处理（从匹配文档最少的词项开始），可快速缩小结果集，减少后续合并操作的计算量，提升查询效率。

8. 位置索引（Positional Index）相比普通倒排索引的扩展是？（ ）

A\. 仅存储文档ID B\. 存储词项在文档中的具体位置 C\. 不存储文档频率 D\. 仅支持单词查询

答案：B

解析：位置索引在postings列表中新增词项的位置信息（如在文档中的偏移量），支持短语查询、邻近查询（如“federal /2 tort”），功能更强大。

9. 倒排索引中“跳表指针（Skip Pointers）”的核心作用是？（ ）

A\. 增加索引存储量 B\. 跳过无需匹配的postings条目，加速合并过程 C\. 支持模糊查询 D\. 替代词典

解析：跳表指针在postings列表中每隔固定间隔设置，查询时可跳过不可能匹配的文档ID，减少遍历次数，提升AND/OR等操作的合并效率。

1. 向量空间模型（VSM）的核心思想是？（ ）

A\. 基于布尔逻辑的精确匹配 B\. 将文档和查询表示为向量，通过相似度排序 C\. 仅使用词频排序 D\. 无需词项加权

答案：B

解析：VSM的核心是将文档和查询映射到高维向量空间，通过计算向量间的相似度（如余弦相似度）衡量相关性，实现排序检索。

2. tf\-idf的核心逻辑是？（ ）

A\. 仅考虑词项在文档中的频率 B\. 仅考虑词项在语料库中的频率 C\. 结合词项在文档中的频率（tf）和语料库中的稀有度（idf） D\. 与词项频率无关

答案：C

解析：tf\-idf = tf权重 × idf权重，既体现词项在文档中的重要性（tf越高越重要），也体现词项的全局信息量（idf越高，词项越稀有，信息量越大）。

3. 词项频率（tf）的对数加权公式（1\+log\(tfₜ,d\)）的目的是？（ ）

A\. 使词频贡献呈线性增长 B\. 抑制高频词的过度影响（边际效益递减） C\. 增加低频词的权重 D\. 使词频为0时权重为1

答案：B

解析：原始词频与相关性并非线性关系（10次出现≠10倍相关），对数加权让词频增长的贡献逐渐递减，避免高频词主导评分。

4. 逆文档频率（idf）的计算公式是？（ ）

A\. log\(N/dfₜ\) B\. dfₜ/N C\. N/dfₜ D\. log\(dfₜ/N\)

答案：A

解析：idf = log\(N/dfₜ\)，其中N为语料库文档总数，dfₜ为含词项t的文档数，对数用于减弱idf的极端值影响。

5. 余弦相似度的取值范围是？（ ）

A\. \(\-∞, \+∞\) B\. \[0, 1\] C\. \[\-1, 1\] D\. \[0, \+∞\)

答案：B

解析：文档和查询向量的元素均为非负加权值（tf\-idf≥0），因此余弦相似度取值范围为\[0,1\]，1表示完全相似，0表示无共同词项。

6. 向量空间模型中“长度归一化”的核心目的是？（ ）

A\. 增加向量维度 B\. 消除文档长度对相似度的影响（如长文档与短文档公平比较） C\. 减少词项数量 D\. 替代tf\-idf加权

答案：B

解析：长文档可能因词项多导致向量长度更长，归一化（如L2归一化）将向量转为单位向量，使相似度仅依赖夹角，与长度无关。

7. 以下哪种情况idf值最大？（ ）

A\. 词项在1000个文档中出现（N=10000） B\. 词项在100个文档中出现（N=10000） C\. 词项在10000个文档中出现（N=10000） D\. 词项在1个文档中出现（N=10000）

答案：D

解析：idf与dfₜ（含词项的文档数）成反比，dfₜ越小，idf越大，词项越稀有，信息量越大。

8. 布尔检索与向量空间模型的核心区别是？（ ）

A\. 布尔检索支持排序，VSM不支持 B\. 布尔检索是二元匹配（匹配/不匹配），VSM是相似度排序 C\. VSM仅支持单词查询 D\. 布尔检索需向量表示

答案：B

解析：布尔检索基于逻辑运算，无相关性排序；VSM通过向量相似度实现排序，能区分文档相关性高低。

10. 余弦相似度计算中，若文档和查询向量的夹角为0°，则相似度为？（ ）

1. 信息检索中，Precision（精确率）的定义是？（ ）

A\. 检索到的相关文档数 / 总相关文档数 B\. 检索到的相关文档数 / 检索到的总文档数 C\. 未检索到的相关文档数 / 总相关文档数 D\. 检索到的无关文档数 / 检索到的总文档数

答案：B

解析：精确率衡量检索结果的“纯度”，即检索到的文档中真正相关的比例，核心是“少返回无关文档”。

2. 信息检索的评价指标中，Recall（召回率）的核心作用是？（ ）

A\. 衡量检索结果的纯度 B\. 衡量是否遗漏相关文档（覆盖度） C\. 仅适用于二分类任务 D\. 与精确率完全正相关

答案：B

解析：召回率衡量检索系统的“覆盖能力”，即总相关文档中被成功检索到的比例，核心是“不遗漏相关文档”。

3. 信息检索中，F₁分数是以下哪两个指标的调和平均数？（ ）

A\. 精确率和召回率 B\. 准确率和错误率 C\. P@K和MAP D\. DCG和NDCG

答案：A

解析：F₁ = 2×\(Precision×Recall\)/\(Precision\+Recall\)，是精确率和召回率的调和平均，用于综合两者的性能。

4. 信息检索中不适合用Accuracy（准确率）作为评估指标的原因是？（ ）

A\. 计算复杂 B\. 对海量无关文档敏感，结果无意义 C\. 无法衡量相关性 D\. 仅适用于排序任务

答案：B

解析：IR场景中绝大多数文档为无关文档，即使检索系统返回空结果，准确率也接近100%，无法反映系统真实性能。

5. 信息检索的评价指标中，Precision@K（P@K）的含义是？（ ）

A\. 前K个检索结果中的相关文档比例 B\. 总相关文档中前K个检索到的比例 C\. 第K个文档的相关概率 D\. 前K个文档的平均召回率

答案：A

解析：P@K聚焦“Top\-K结果的纯度”，适用于用户只关注前几名结果的场景（如网页搜索）。

6. 信息检索中，Mean Average Precision（MAP）的核心思想是？（ ）

A\. 仅关注前K个结果 B\. 综合考虑所有相关文档的排名位置 C\. 仅适用于单查询 D\. 与召回率无关

答案：B

解析：MAP先计算每个查询的平均精度（AP，在每个相关文档的排名位置计算精确率并平均），再对所有查询取平均，能反映排序质量。

7. 信息检索中，Mean Reciprocal Rank（MRR）适用于哪种场景？（ ）

A\. 需检索多个相关文档的场景 B\. 仅需检索一个相关文档的场景（如已知项搜索） C\. 多等级相关性评估 D\. 仅适用于布尔检索

答案：B

解析：MRR计算首个相关文档排名的倒数平均值，核心是“快速找到第一个正确结果”，适配导航式查询、事实查询等场景。

8. 信息检索中，NDCG（归一化折损累积增益）的核心改进是？（ ）

A\. 仅适用于二分类相关性 B\. 考虑文档的等级相关性（如“高度相关”“一般相关”）和排名位置 C\. 与精确率完全等价 D\. 无需归一化处理

答案：B

解析：NDCG突破了二分类相关性限制，既考虑文档的等级相关性权重，又通过对数折损惩罚排名靠后的文档，还能跨查询比较。

9. 以下哪种情况适合优先关注Recall（召回率）？（ ）

A\. 网页搜索（用户关注前10条结果） B\. 法律文档检索（需全面找到所有相关案例，避免遗漏） C\. 电商商品推荐（需精准推荐） D\. 学术论文快速筛选

解析：召回率优先的场景需“全覆盖相关文档”，即使返回部分无关文档也可接受，如法律、医疗等需避免遗漏关键信息的领域。

10. 理想情况下，信息检索的评价指标NDCG（归一化折损累积增益）的最大值是？（ ）

答案：C

1. ItemCF（基于物品的协同过滤）的核心假设是？（ ）

A\. 兴趣相似的用户喜欢相似物品 B\. 喜欢某物品的用户也会喜欢与之相似的物品 C\. 热门物品适合所有用户 D\. 用户只喜欢未接触过的物品

答案：B

解析：ItemCF的核心逻辑是“物品相似性传递”——用户喜欢物品A，而A与B相似，则用户大概率喜欢B，物品相似度由用户重合度计算。

2. UserCF与ItemCF的核心区别是？（ ）

A\. UserCF基于用户相似度推荐，ItemCF基于物品相似度推荐 B\. UserCF仅适用于冷启动，ItemCF仅适用于热启动 C\. UserCF无需计算相似度，ItemCF需要 D\. UserCF是精排算法，ItemCF是召回算法

答案：A

解析：UserCF先找兴趣相似的用户，推荐相似用户喜欢的物品；ItemCF先找物品的相似物品，推荐给喜欢该物品的用户，两者均为召回算法。

3. 双塔模型的核心优势是？（ ）

解析：双塔模型分为用户塔（处理用户特征）和物品塔（处理物品特征），独立输出向量，物品向量可离线存储，线上通过向量检索快速召回，适配亿级物品场景。

5. Look\-Alike召回在冷启动中的核心作用是？（ ）

# 简答题

1. 请简述倒排索引的构成及构建流程。

答案：倒排索引是现代信息检索的核心数据结构，主要由两部分构成：一是字典，存储所有 distinct 术语（term），并关联术语的文档频率、指向 postings list 的指针；二是 postings list，存储包含该术语的文档 ID 列表（通常按文档 ID 排序），部分还会记录术语在文档中的位置信息。其构建流程如下：首先对文档集合进行文本预处理，包括分词（将文本切分为单词令牌）、归一化（统一大小写、处理缩写等）、词干提取和停用词过滤；然后生成（术语 \- 文档 ID）键值对序列；接着按术语排序并合并同一术语的文档 ID，形成 postings list；最后构建字典，关联术语与对应的 postings list 及文档频率信息。

2. 什么是 tf\-idf 权重？请分别解释 tf 和 idf 的含义及计算逻辑。

答案：tf\-idf 权重是信息检索中常用的术语加权方案，用于衡量术语在文档中的重要性，核心是 “词频越高、文档频率越低，术语越重要”。tf（Term Frequency，词频）指术语 t 在文档 d 中出现的次数，计算逻辑为术语 t 在 d 中的出现次数，为避免相关性随词频线性增长，常采用对数形式（1\+log \(tf\)，tf\>0 时；否则为 0）。idf（Inverse Document Frequency，逆文档频率）反映术语的全局区分度，计算逻辑为 log \(N/df\)（N 为集合中文档总数，df 为包含术语 t 的文档数），目的是降低高频术语（如停用词）的权重，提升稀有术语的权重。最终 tf\-idf 权重为 tf 值与 idf 值的乘积。

3. 信息检索中常用的评估指标有哪些？请简述 Precision、Recall 和 F1\-measure 的定义。

答案：信息检索常用评估指标包括 Precision（精确率）、Recall（召回率）、F1\-measure、MAP（平均平均精度）、NDCG（归一化折扣累积增益）等。Precision 指检索出的相关文档占所有检索文档的比例，公式为 P=TP/\(TP\+FP\)，反映检索结果的 “纯净度”；Recall 指检索出的相关文档占集合中所有相关文档的比例，公式为 R=TP/\(TP\+FN\)，反映检索结果的 “全面性”；F1\-measure 是 Precision 和 Recall 的调和平均数，公式为 F1=2PR/\(P\+R\)，用于综合平衡两者，当 Precision 和 Recall 同等重要时使用，其值越大说明检索效果越好。

4. 请简述 CNN 的核心设计思想及两个关键机制（感受野和参数共享）的作用。

答案：CNN 的核心设计思想是模拟人类视觉系统，通过捕捉图像中的局部特征并逐步组合为高阶特征，适配网格结构数据（如图像）的处理，避免全连接网络的参数冗余。感受野指神经元在输入图像上感知的局部区域，其作用是让神经元无需关注整个图像，仅聚焦局部关键模式（如边缘、纹理），降低计算复杂度；参数共享指同一卷积核在整个输入图像上重复使用相同参数，其作用是减少模型参数数量，提升训练效率，同时利用图像中相同模式在不同区域重复出现的特性，增强模型泛化能力。

5. RNN 与传统前馈神经网络的核心区别是什么？LSTM 如何解决 RNN 的梯度消失问题？

答案：RNN 与传统前馈神经网络的核心区别在于 RNN 引入了 “记忆” 机制，通过隐藏层状态的循环传递，能够处理变长序列数据（如文本、语音），捕捉序列中的时序依赖关系，而前馈神经网络无法利用历史信息，仅能处理固定长度的输入。RNN 存在梯度消失问题（长期依赖信息传递时梯度趋近于 0），LSTM 通过设计门控机制解决该问题：遗忘门控制是否保留历史细胞状态信息，输入门决定新信息是否加入细胞状态，输出门控制细胞状态如何映射为隐藏层输出；细胞状态（cell state）采用线性更新方式，梯度传递时不易衰减，同时门控结构可动态调节信息的保留与遗忘，从而有效捕捉长期时序依赖。

6. 自注意力机制的核心作用是什么？与 CNN、RNN 相比，它有哪些优势？

答案：自注意力机制的核心作用是在序列数据中，通过计算每个位置与其他所有位置的注意力分数，自适应地捕捉位置间的依赖关系，无需依赖固定的局部窗口或时序顺序。与 CNN、RNN 相比，它的优势主要有三点：一是并行计算能力强，CNN 需按局部窗口滑动计算，RNN 需按时序顺序迭代，而自注意力可同时计算所有位置的依赖关系，训练效率更高；二是长距离依赖捕捉能力更强，CNN 的感受野需通过堆叠层扩大，RNN 易受梯度消失影响，自注意力可直接建模任意两个位置的关联；三是灵活性高，能够自适应分配注意力权重，更精准地聚焦关键信息。

9. 推荐系统的召回环节有哪些常用方法？请举例说明至少三种。

答案：推荐系统召回环节的核心是从海量物品中快速筛选出用户可能感兴趣的候选集，常用方法包括：一是协同过滤类方法，如 ItemCF（基于物品相似度，推荐与用户历史喜欢物品相似的物品）、UserCF（基于用户相似度，推荐相似用户喜欢的物品）；二是深度学习类方法，如双塔模型（将用户和物品分别通过神经网络映射为向量，计算余弦相似度进行召回）；三是基于内容或属性的方法，如类目 / 关键词召回（根据用户感兴趣的类目或关键词，匹配具有对应属性的物品）、地理位置召回（基于用户定位，推荐附近的优质内容）；此外还有聚类召回（将物品聚类，推荐用户感兴趣聚类中的物品）、Look\-Alike 召回（基于种子用户扩散，找到相似用户喜欢的物品）等。

10. 什么是物品冷启动问题？解决该问题的主要思路有哪些？

答案：物品冷启动问题指新发布的物品因缺乏用户交互数据（如点击、点赞），无法通过传统依赖交互数据的方法（如 ItemCF、双塔模型 ID 嵌入）进行有效推荐的问题。解决该问题的主要思路的是利用物品自身属性和内容信息，而非用户交互数据：一是基于内容的召回，如类目 / 关键词召回（利用物品的类目、标签、关键词等属性匹配用户兴趣）；二是聚类召回（通过 CNN、BERT 等模型提取物品图文内容特征，聚类后推荐用户感兴趣聚类中的新物品）；三是 Look\-Alike 召回（将与新物品有交互的用户作为种子用户，扩散到相似用户群体进行推荐）；四是改进双塔模型，如为新物品分配默认嵌入或利用相似高曝光物品的嵌入均值作为初始化。

11. 向量空间模型中，为何使用余弦相似度而非欧氏距离进行文档与查询的匹配？

答案：向量空间模型中，文档和查询均被表示为高维向量，核心需求是衡量两者的 “语义相似性” 而非 “空间距离”。欧氏距离的缺陷在于其受向量长度影响显著：同一文档若重复多次，向量长度会增大，欧氏距离会随之变化，但语义并未改变；而余弦相似度衡量的是两个向量的夹角余弦值，仅关注向量的方向（即术语的相对分布），不受向量长度的影响，更符合语义相似性的定义。例如，文档 d 和其复制版 d' 的欧氏距离较大，但余弦相似度为 1，准确反映了两者语义完全一致的特性，因此余弦相似度更适合文档与查询的匹配场景。

12. 概率检索模型中，Jelinek\-Mercer 平滑的核心思想是什么？它如何解决参数估计中的零概率问题？

答案：Jelinek\-Mercer 平滑的核心思想是通过混合文档自身的术语概率和集合层面的术语概率，对术语的条件概率进行估计，避免单一依赖文档数据导致的偏差。其具体公式为 P \(t\|d\)=λP \(t\|M_d\)\+\(1\-λ\) P \(t\|M_c\)，其中 λ 为平滑参数，P \(t\|M_d\) 是术语 t 在文档 d 中的最大似然估计概率，P \(t\|M_c\) 是术语 t 在整个集合中的概率。在参数估计中，若术语 t 未在文档 d 中出现，P \(t\|M_d\) 会为零，导致整个查询概率为零（一票否决问题）；而 Jelinek\-Mercer 平滑通过引入集合概率 P \(t\|M_c\)，让未在文档中出现的术语仍有非零概率，有效解决了零概率问题，同时 λ 的取值可平衡文档特异性和集合通用性。

1. Inverted Index（倒排索引）相比于线性扫描（Linear scan），为什么它是现代信息检索的核心数据结构？

答案：Inverted Index 优于线性扫描的原因在于：

- **效率**：线性扫描在文档集合很大（如 $N=100$万文档）时非常慢，因为需要遍历所有文档。倒排索引允许系统直接定位包含查询词的文档，避免处理不相关的文档。

- **支持复杂查询**：倒排索引更容易支持邻近查询（Proximity queries）等操作，而线性扫描很难高效实现这一点。

2. 在倒排索引构建中，**Skip pointers**（跳跃指针）的作用是什么？

答案：Skip pointers 用于加速倒排记录表（Postings list）的合并（Merge）过程。如果在处理 AND 查询时，当前文档 ID 远小于另一个列表的当前 ID，可以通过 Skip pointers 跳过中间的文档，避免逐个比较，从而达到 $O(x+y)$ 以下的时间复杂度。

3. 在处理布尔查询 `(A OR B) AND (C OR D)` 时，为了优化查询处理速度，应该采用什么策略？

答案：应该按照 **Document Frequency**（文档频率）从小到大的顺序处理。 具体来说：

- 先估算每个 OR 子句的大小（通常保守估计为词项文档频率之和）。

- 按估算后的大小递增顺序处理这些组件。先处理结果集较小的部分可以尽早减少中间结果集的大小，从而减少后续合并操作的工作量。

4. 在 **Vector Space Model** 中，计算 Query 和 Document 之间的相似度为什么使用 **Cosine Similarity** 而不是欧几里得距离（Euclidean distance）？

答案：欧几里得距离对向量的长度非常敏感。如果一篇文档很长（包含很多词），其向量模长很大，即便它与查询在内容分布上非常相似，欧几里得距离也会很大（显示为不相似）。Cosine Similarity 通过长度归一化消除了文档长度的影响，只关注方向（即内容的分布）。

5. Okapi BM25 相比于传统的 BIM 模型做了哪些改进？公式中的参数 $k_1$ 和 $b$ 分别控制什么？

答案：BM25 在 BIM 的基础上引入了 **Term Frequency \(tf\)**（非二值）和 **Document Length Normalization**。它更适合现代全文搜索。

- $k_1$：控制词频（tf）的饱和度。当 $k_1=0$ 时退化为二值模型；$k_1$ 越大，词频的作用越明显（通常取 1\.2 到 2\.0）。

- $b$：控制文档长度归一化的力度 \($0 \le b \le 1$\)。$b=1$ 表示完全归一化，$b=0$ 表示不进行长度归一化。

6. 在信息检索的 **Language Model \(LM\)** 方法中，基本的思想是如何对文档进行排序的？

答案： LM 方法将每个文档 $d$ 视为一个生成模型 $M_d$。对于给定的查询 $q$，我们计算该文档模型生成这个查询的概率 $P(q|M_d)$。文档按照这个生成概率的大小进行排序。即：我们寻找最可能“生成”出用户查询的那个文档模型。

7. 定义 **Precision**（查准率）和 **Recall**（查全率），并解释它们之间的 Trade\-off（权衡）。

答案：

- **Precision** = TP / \(TP \+ FP\)：检索到的文档中，相关文档所占的比例（用户看到的有多少是没用的？）。

- **Recall** = TP / \(TP \+ FN\)：所有相关文档中，被系统检索到的比例（系统漏掉了多少好东西？）。

- **Trade\-off**：通常情况下，提高 Recall 会降低 Precision（例如返回所有文档，Recall 为 100%，但 Precision 极低）；提高 Precision 往往会降低 Recall（只返回最确定的那一个文档）。

1. 简述推荐系统链路中 “召回 \- 粗排 \- 精排 \- 重排” 各阶段的核心目标和特点。

**答案**：

- **召回**：核心目标是从海量物品库中快速筛选出用户可能感兴趣的数千个候选物品，特点是速度快、模型简单，需兼顾覆盖度和初步相关性，常见策略有双塔模型、ItemCF、类目召回等。

- **粗排**：核心目标是对召回的数千个物品做初步排序，筛选出数百个优质物品送入精排，特点是模型复杂度适中、计算效率较高，在召回基础上提升排序精准度，常用三塔模型等轻量级模型。

- **精排**：核心目标是对粗排输出的数百个物品做精准排序，特点是模型复杂度高、预测精准，会融合多维度特征和多目标预估（点击率、点赞率等），是决定推荐效果的核心环节。

- **重排**：核心目标是提升推荐结果的多样性和用户体验，特点是在精排排序基础上，通过 MMR、DPP 等算法打散相似物品，同时满足业务规则（如控制广告频率）。

2. 对比 BERT 和 GPT 的预训练方式、模型结构及核心能力差异。

**答案**：

- **预训练方式**：
    - BERT 采用**双向 Masked Language Model（MLM）和下一句预测（NSP）**，MLM 随机掩码输入序列中的词项并预测，能捕捉双向上下文信息；

    - GPT 采用**单向自回归语言建模**，通过前文预测下一个词项，仅能捕捉单向上下文信息。

- **模型结构**：
    - BERT 基于**Transformer 编码器**，编码器的自注意力为双向注意力；

    - GPT 基于**Transformer 解码器**，解码器采用掩码自注意力，仅能关注前文。

- **核心能力**：
    - BERT 擅长**理解类任务**，如文本分类、命名实体识别、问答等；

    - GPT 擅长**生成类任务**，如文本续写、对话生成、摘要生成等。

在推荐系统中，ItemCF和UserCF的基本思想是什么？它们的主要区别在哪里？

答案：

ItemCF（物品协同过滤）的基本思想是：如果用户喜欢物品A，且物品A与物品B相似，那么用户很可能喜欢物品B。UserCF（用户协同过滤）的基本思想是：如果用户A与用户B相似，且用户B喜欢某物品，那么用户A也很可能喜欢该物品。主要区别在于：ItemCF通过计算物品之间的相似度（基于喜欢两个物品的用户重叠度）来推荐，适合物品数量相对稳定的场景；UserCF通过计算用户之间的相似度（基于两个用户喜欢的物品重叠度）来推荐，适合用户兴趣变化较快的场景。ItemCF的召回流程是：用户→用户喜欢的物品→相似物品；UserCF的召回流程是：用户→相似用户→相似用户喜欢的物品。

什么是双塔模型？它在召回阶段有什么优势？

答案：

双塔模型是一种用于推荐的神经网络架构，包含用户塔和物品塔两个独立的网络。用户塔输入用户特征（如用户ID、离散特征、统计特征等），输出用户向量；物品塔输入物品特征，输出物品向量。两个向量的余弦相似度作为用户对物品兴趣的预估值。在召回阶段的优势主要体现在：离线训练完成后，可以将所有物品向量预先存储到向量数据库中；线上召回时，只需计算一次用户向量，然后通过近似最近邻查找（如Faiss、Milvus）快速找到最相似的k个物品，计算量小、速度快。相比之下，精排模型需要对每个候选物品都做一次完整推理，计算量大。双塔模型通过分离用户和物品的特征处理，实现了高效的召回。

什么是推荐系统中的重排？MMR算法如何提升推荐结果的多样性？

答案：

重排是在精排之后、最终展示之前的环节，主要目的是在保证推荐质量的同时提升多样性，避免推荐结果过于单一。MMR（Maximal Marginal Relevance）是一种常用的多样性算法。MMR在每一轮选择物品时，不仅考虑物品的精排分数（reward），还考虑它与已选中物品的相似度。MMR的分数公式为：MR_i = θ·reward_i \- \(1\-θ\)·max\(sim\(i,j\)\)，其中θ是平衡参数，sim\(i,j\)是物品i与已选中物品j的相似度。算法首先选择精排分数最高的物品，然后在剩余物品中选择MR分数最高的物品，重复k次。这样既保证了推荐质量（通过reward项），又保证了多样性（通过相似度惩罚项）。为了避免已选中物品过多导致多样性分数饱和，通常使用滑动窗口机制，只考虑最近选中的若干物品。

什么是推荐系统中的物品冷启动问题？有哪些常见的解决方法？

答案：

物品冷启动是指新发布的物品缺少用户交互数据，导致推荐系统难以准确推荐的问题。常见解决方法包括：第一，改进双塔模型，新物品使用default embedding或利用相似高曝光物品的embedding向量；第二，类目和关键词召回，根据物品的类目、关键词等属性特征，从用户画像中找到感兴趣的类目/关键词，召回该类目/关键词下的最新笔记；第三，聚类召回，离线训练内容相似度模型，将物品映射到向量空间并聚类，线上根据用户历史行为找到感兴趣的cluster，召回该cluster下的新物品；第四，Look\-Alike召回，将有交互的用户作为种子用户，通过用户相似度扩散到相似用户；第五，流量调控，通过提权（boost）和保量机制，确保新物品获得足够的曝光机会。

13. 什么是过拟合？线性回归中如何缓解过拟合？

答案：① 过拟合定义：模型在训练数据上表现极好（误差小），但在未见过的测试数据上表现差（误差大），本质是模型过度拟合训练数据中的噪声，而非学习到普遍规律；② 缓解方法：a\. 正则化：在损失函数中加入L1（Lasso）或L2（Ridge）正则项，惩罚参数绝对值，使模型更平滑；b\. 特征选择：剔除冗余、无关的特征，降低模型维度；c\. 增加训练数据：用更多数据让模型学习普遍规律，减少噪声影响；d\. 简化模型：选择低复杂度模型（如线性特征而非高次多项式特征）。

15. 线性回归的“泛化能力”指什么？为什么测试集误差通常大于训练集误差？

答案：① 泛化能力：模型对未参与训练的新数据（测试数据）的预测能力，是衡量模型实用性的核心指标；② 测试集误差大于训练集误差的原因：a\. 训练过程中模型是基于训练数据优化的，天然更贴合训练数据的分布；b\. 测试数据与训练数据存在分布差异（即使来自同一总体，也存在随机波动）；c\. 模型可能学习到训练数据中的噪声，这些噪声在测试数据中不存在，导致测试误差升高；d\. 过拟合场景下，模型过度贴合训练数据细节，对测试数据的适配性大幅下降，误差差距会更明显。

15. 解释Softmax函数的数学形式与物理意义。

答案：① 数学形式：对于k分类任务，给定线性输出z₁,z₂,…,zₖ（zᵢ=wᵢ·x \+ bᵢ），Softmax函数将其转换为类别概率pᵢ = e^zᵢ / Σ（j=1到k）e^zⱼ；② 物理意义：a\. 归一化：将任意线性输出转换为\[0,1\]区间的概率，且所有类别概率之和为1，满足概率分布的基本要求；b\. 放大差异：指数函数会放大不同zᵢ之间的差距，使“优势类别”的概率更接近1，“劣势类别”的概率更接近0，增强分类的确定性；c\. 概率解释：pᵢ表示输入x属于类别i的概率，可直接用于多分类决策（选择概率最大的类别）。

12. 为什么深层神经网络训练需要反向传播算法？梯度下降与反向传播的关系是什么？

答案：① 反向传播的必要性：深层神经网络包含大量参数（权重w、偏置b），直接计算损失函数对每个参数的梯度极其复杂；反向传播通过链式法则，从输出层反向推导各层参数的梯度，大幅降低计算复杂度，使深层网络的参数优化可行。② 两者关系：反向传播是“计算梯度的方法”，梯度下降是“利用梯度更新参数的优化算法”；反向传播为梯度下降提供关键的梯度信息，梯度下降依赖这些梯度沿负方向调整参数，两者协同完成模型训练——先通过反向传播算梯度，再通过梯度下降更参数。

13. 简述深度学习与传统机器学习（如逻辑回归、SVM）的核心区别。

答案：① 特征提取方式：传统机器学习依赖人工特征工程（如手动设计图像的边缘特征、文本的TF\-IDF特征），深度学习通过多层网络自动学习高层抽象特征（无需人工干预）；② 模型结构：传统机器学习多为浅层模型（如逻辑回归无隐藏层、SVM仅含核函数映射），深度学习是含多个隐藏层的深层模型；③ 数据与算力需求：传统机器学习对数据量要求较低，算力需求小；深度学习需海量训练数据才能充分学习特征，且依赖GPU等算力支持；④ 表达能力：传统机器学习难以处理复杂非线性问题（如图像识别、自然语言理解），深度学习通过多层非线性变换，具备更强的复杂规律学习能力。

14. 什么是“梯度消失”？深层神经网络中如何缓解这一问题？

答案：① 梯度消失定义：训练深层网络时，梯度通过反向传播从输出层向输入层传递，若使用Sigmoid等激活函数，梯度会随着层数增加逐渐趋近于0，导致浅层参数更新停滞，模型无法学习。② 缓解方法：a\. 更换激活函数：用ReLU（梯度在正区间恒为1）替代Sigmoid，避免梯度衰减；b\. 残差连接：如Residual Net的跳跃连接，让梯度直接传递到浅层；c\. 批量归一化（Batch Normalization）：标准化各层输入，稳定梯度分布；d\. 合理初始化参数：避免初始参数过大或过小，减少梯度衰减的初始影响。

15. 卷积神经网络（CNN）除了图像分类，还可应用于哪些领域？请举例说明并简要解释适配性。

答案：① 自然语言处理（NLP）：如TextCNN用于文本分类，将文本的词向量矩阵视为“文本图像”（序列长度×词向量维度），通过卷积核提取局部语义特征（如短语、短句），适配文本的局部语义相关性；② 语音识别：将语音的频谱图（时间×频率）视为二维图像，CNN提取频谱图的局部特征（如声调、音节），适配语音的时频局部相关性；③ 围棋/棋盘游戏：如AlphaGo将围棋棋盘（19×19）视为二维网格，CNN提取局部棋形特征（如活棋、断点），适配棋盘的局部战术规律；④ 目标检测：如YOLO、Faster R\-CNN，通过CNN提取图像特征并预测目标的位置和类别，适配目标在图像中的局部存在特性。

15. RNN系列模型在自然语言处理（NLP）中有哪些典型应用？请举例说明并简要解释适配性。

答案：① 文本生成：如诗歌生成、对话系统，RNN/LSTM/GRU能建模词语间的时序依赖，按顺序生成连贯文本；② 机器翻译：如英文到中文翻译，序列到序列模型（编码器\+解码器）\+ Attention机制能处理输入输出长度不同的序列，适配翻译任务；③ 情感分析：如判断文本正面/负面情绪，双向RNN能捕捉上下文依赖（如转折关系），提升分析精度；④ 命名实体识别：如识别文本中的人名、地名，双向RNN\+CRF能利用双向时序信息，准确标注实体边界；⑤ 语音识别：如语音转文字，CTC\+GRU能处理语音序列与文本序列的对齐问题，适配无标注对齐的场景。

15. 自注意力（Self\-attention）在自然语言处理（NLP）和计算机视觉（CV）中的典型应用有哪些？

答案：① NLP领域：a\. 机器翻译（Transformer模型的核心组件），捕捉词语间语义依赖；b\. 文本分类/情感分析（BERT模型），捕捉上下文语义；c\. 命名实体识别，捕捉实体与上下文的关联；d\. 文本生成，建模词语时序依赖；② CV领域：a\. 图像分类（Vision Transformer，ViT），将图像patch视为序列，捕捉patch间关联；b\. 目标检测（DETR），用自注意力替代锚框，建模目标间关系；c\. 图像生成（Self\-Attention GAN），提升生成图像的细节一致性；d\. 语义分割，捕捉像素与区域的关联。

12. 解释BERT与GPT的核心差异（结构、预训练任务、适用场景）。

答案：① 结构差异：BERT基于Transformer Encoder（双向注意力），无掩码机制；GPT基于Transformer Decoder（掩码自注意力），避免未来信息泄露；② 预训练任务差异：BERT是自编码模型（Autoencoder），核心任务是掩码预测（双向上下文）；GPT是自回归模型（Autoregressive），核心任务是下一个token生成（单向上下文）；③ 适用场景差异：BERT适配语义理解类任务（文本分类、问答、命名实体识别）；GPT适配文本生成类任务（诗歌生成、对话系统、文本续写）。

11. 简述LMIR（语言模型检索）的核心思想与排序逻辑。

答案：① 核心思想：将每个文档视为一个语言模型，假设用户的查询是从该模型中随机生成的；② 排序逻辑：按文档生成查询的概率P\(q\|d\)降序排列文档；③ 概率推导：根据贝叶斯公式，P\(d\|q\) ∝ P\(q\|d\)P\(d\)，由于P\(q\)对所有文档相同，且默认P\(d\)均匀（所有文档先验概率相同），因此排序等价于按P\(q\|d\)排序。

14. 简述LMIR（语言模型检索）与向量空间模型（VSM）的核心区别。

答案：① 理论基础：LMIR基于概率论（生成模型），VSM基于线性代数（几何相似度）；② 核心指标：LMIR用P\(q\|d\)（生成概率）排序，VSM用余弦相似度排序；③ 词频与归一化：LMIR用原始词频，概率本身隐含长度归一化；VSM需单独进行长度归一化（如余弦归一化）；④ 全局信息利用：LMIR通过平滑融合语料库概率（类似IDF的作用），VSM直接使用IDF加权。

16. 已知语料库包含两个文档：d1（“Xerox reports a profit but revenue is down”，长度\|d1\|=8）、d2（“Lucene narrows quarter loss but revenue decreases further”，长度\|d2\|=8）；查询q=“revenue down”；语料库总词数T=16，cf_revenue=2（revenue在语料库出现2次），cf_down=1（down在语料库出现1次）。使用Jelinek\-Mercer平滑（λ=1/2）计算P\(q\|d1\)和P\(q\|d2\)，并排序。

答案：

步骤1：明确核心公式

P\(q\|d\) = P\(revenue\|d\) × P\(down\|d\)

其中，P\(t\|d\) = \[λ×\(tf_t,d/\|d\|\) \+ \(1\-λ\)×\(cf_t/T\)\]

步骤2：计算各词项的概率

- 词项“revenue”：tf_revenue,d1=1，tf_revenue,d2=1

P\(revenue\|d1\) = \(1/2×1/8\) \+ \(1/2×2/16\) = 1/16 \+ 1/16 = 2/16 = 1/8

P\(revenue\|d2\) = 同d1 = 1/8

- 词项“down”：tf_down,d1=1，tf_down,d2=0

P\(down\|d1\) = \(1/2×1/8\) \+ \(1/2×1/16\) = 1/16 \+ 1/32 = 3/32

P\(down\|d2\) = \(1/2×0/8\) \+ \(1/2×1/16\) = 0 \+ 1/32 = 1/32

步骤3：计算P\(q\|d\)

- P\(q\|d1\) = 1/8 × 3/32 = 3/256 ≈ 0\.0117

- P\(q\|d2\) = 1/8 × 1/32 = 1/256 ≈ 0\.0039

    步骤4：排序

    d1 \> d2（P\(q\|d1\) \> P\(q\|d2\)）

    最终答案：P\(q\|d1\)=3/256，P\(q\|d2\)=1/256，排序为d1优于d2。

17. 沿用第1题的文档和语料库信息，使用Dirichlet平滑（α=8）计算P\(q\|d1\)和P\(q\|d2\)（提示：P\(t\|Mc\)=cf_t/T）。

答案：

步骤1：明确核心公式

P\(t\|d\) = \(tf_t,d \+ α×P\(t\|Mc\)\) / \(\|d\| \+ α\)

P\(q\|d\) = P\(revenue\|d\) × P\(down\|d\)

步骤2：计算P\(t\|Mc\)

- P\(revenue\|Mc\) = cf_revenue/T = 2/16 = 1/8

- P\(down\|Mc\) = cf_down/T = 1/16

    步骤3：计算各词项的P\(t\|d\)

- 词项“revenue”：

P\(revenue\|d1\) = \(1 \+ 8×1/8\)/\(8\+8\) = \(1\+1\)/16 = 2/16 = 1/8

P\(revenue\|d2\) = \(1 \+ 8×1/8\)/16 = 2/16 = 1/8

- 词项“down”：

P\(down\|d1\) = \(1 \+ 8×1/16\)/\(16\) = \(1 \+ 0\.5\)/16 = 1\.5/16 = 3/32

P\(down\|d2\) = \(0 \+ 8×1/16\)/16 = \(0\.5\)/16 = 1/32

步骤4：计算P\(q\|d\)

- P\(q\|d1\) = 1/8 × 3/32 = 3/256 ≈ 0\.0117

- P\(q\|d2\) = 1/8 × 1/32 = 1/256 ≈ 0\.0039

    最终答案：P\(q\|d1\)=3/256，P\(q\|d2\)=1/256，排序为d1优于d2。

11. 简述倒排索引的核心优势及构建流程。

答案：① 核心优势：a\. 存储高效（仅存储非零元素，解决稀疏矩阵问题）；b\. 查询快速（直接定位含查询词的文档，无需遍历所有文档）；c\. 支持多种查询（布尔、短语、邻近查询）。② 构建流程：a\. 文本预处理：分词（Tokenization）、归一化（大小写统一、词干提取、停用词过滤）；b\. 生成词项\-文档ID对：记录每个词项在哪些文档中出现；c\. 排序：按词项字典序\+文档ID升序排序；d\. 合并与构建：合并同一词项的文档ID，生成postings列表，构建词典（含词项、文档频率、postings指针）。

12. 解释布尔检索模型的优缺点及适用场景。

答案：① 优点：a\. 逻辑清晰，易于理解和实现；b\. 查询速度快（基于倒排索引的合并操作）；c\. 精确匹配，适合需要明确结果的场景。② 缺点：a\. 无相关性排序，无法区分文档优先级；b\. 对查询语法要求高（需正确使用AND/OR/NOT）；c\. 无法处理模糊查询、短语查询（普通布尔模型）。③ 适用场景：a\. 结构化数据检索（如邮件、图书馆目录）；b\. 需精确匹配的场景（如法律文档检索）；c\. 简单查询需求（如“含A且不含B”）。

11. 简述tf\-idf加权的计算步骤及各部分的意义。

答案：① 计算词项频率（tf）：统计词项t在文档d中的出现次数tfₜ,d；② tf加权：常用对数加权（1\+log\(tfₜ,d\)），抑制高频词过度影响；③ 计算逆文档频率（idf）：idfₜ=log\(N/dfₜ\)，N为语料库文档总数，dfₜ为含t的文档数，衡量词项的全局信息量；④ 计算tf\-idf：tf\-idfₜ,d = tf加权 × idfₜ，综合词项在文档中的重要性和全局稀有度。

12. 为什么向量空间模型需要长度归一化？常用的归一化方式是什么？

答案：① 归一化的必要性：长文档可能因包含更多词项导致向量长度更长，若不归一化，相似度会偏向长文档，无法公平比较长短文档；② 常用方式：L2归一化（欧几里得归一化），将向量各元素除以向量的L2范数（√Σw²），使向量变为单位向量，相似度仅由夹角决定。

13. 对比布尔检索模型与向量空间模型的优缺点。

答案：① 布尔检索：优点是逻辑清晰、查询速度快；缺点是无相关性排序（要么匹配要么不匹配）、对查询语法要求高、易出现“结果过多或过少”；② 向量空间模型：优点是支持排序检索、能区分相关性高低、对用户更友好（无需布尔语法）；缺点是计算复杂度高（高维向量运算）、依赖词项加权的合理性、忽略词项顺序（词袋模型）。

14. 解释“词袋模型（Bag of Words）”的含义及局限性。

答案：① 含义：将文档视为词项的集合，忽略词项的顺序和语法结构（如“我爱你”和“你爱我”向量相同）；② 局限性：丢失词项的位置信息，无法处理短语查询（如“machine learning”）、歧义句（如“咬死了猎人的狗”），仅能捕捉词项的共现关系。

16. 已知语料库文档总数N=10000，词项t1的文档频率dfₜ₁=100，词项t2的文档频率dfₜ₂=1000。某文档d中t1出现5次，t2出现8次。请计算t1和t2在d中的tf\-idf权重（tf采用对数加权1\+log\(tf\)，idf以10为底）。

答案：

步骤1：计算idf

- idfₜ₁=log₁₀\(N/dfₜ₁\)=log₁₀\(10000/100\)=log₁₀\(100\)=2

- idfₜ₂=log₁₀\(10000/1000\)=log₁₀\(10\)=1

    步骤2：计算tf加权

- tf加权ₜ₁=1\+log₁₀\(5\)=1\+0\.69897≈1\.699

- tf加权ₜ₂=1\+log₁₀\(8\)=1\+0\.90309≈1\.903

    步骤3：计算tf\-idf

- tf\-idfₜ₁=1\.699×2≈3\.398

- tf\-idfₜ₂=1\.903×1≈1\.903

    最终答案：t1的tf\-idf≈3\.40，t2的tf\-idf≈1\.90。

11. 简述精确率（Precision）与召回率（Recall）的权衡关系（Trade\-off）。

答案：① 权衡逻辑：精确率和召回率通常呈反向关系——提高精确率（如严格筛选结果）可能导致召回率下降（遗漏部分相关文档）；提高召回率（如扩大检索范围）可能导致精确率下降（引入更多无关文档）；② 举例：检索时仅返回前3条结果，精确率可能很高但召回率低；返回所有文档，召回率为1但精确率极低；③ 应用场景：需根据需求侧重调整——网页搜索侧重精确率，法律检索侧重召回率，F₁分数可综合两者。

16. 已知某查询的总相关文档数为8篇，检索系统返回10篇文档，其中真正相关的有5篇。请计算精确率（Precision）、召回率（Recall）和F₁分数。

答案：

步骤1：明确核心公式

- 精确率P = 检索到的相关文档数 / 检索到的总文档数 = TP/\(TP\+FP\)

- 召回率R = 检索到的相关文档数 / 总相关文档数 = TP/\(TP\+FN\)

- F₁ = 2×P×R/\(P\+R\)

    步骤2：代入数值计算

- TP=5（检索到的相关文档），TP\+FP=10（检索到的总文档），TP\+FN=8（总相关文档）

- P=5/10=0\.5（50%）

- R=5/8=0\.625（62\.5%）

- F₁=2×0\.5×0\.625/\(0\.5\+0\.625\)=0\.625/\(1\.125\)≈0\.555（55\.5%）

    最终答案：精确率=50%，召回率=62\.5%，F₁≈55\.5%。

14. 为什么推荐系统需要“重排”环节？核心优化手段有哪些？

答案：① 重排的必要性：精排侧重精准度，可能导致结果同质化（如连续推荐同一类笔记），且未考虑平台生态（如广告插入），重排可弥补这些缺陷；② 核心优化手段：a\. 多样性抽样（MMR、DPP），避免内容重复；b\. 规则打散，降低相似笔记的连续展示；c\. 生态调整，插入广告、运营推广内容，平衡用户体验与平台收益。

22. 说明RNN、LSTM、GRU的关系及核心差异。

答案：

- 关系：LSTM和GRU是RNN的改进版本，均用于解决RNN的梯度消失问题，适用于长序列数据；

- 核心差异：LSTM通过输入门、遗忘门、输出门及细胞状态存储长期信息；GRU简化门控结构，仅保留重置门和更新门，参数更少，计算效率更高，效果与LSTM相近。
